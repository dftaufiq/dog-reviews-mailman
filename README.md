One funny one-line review a dog gives the mailman, under 200 characters — an entry for
make.fun's "The Dog Reviews the Mailman" bounty ($3.10 in USDC).

The line: *"Dave knocks, I bark, he runs — 847 times, same dance. Today I broke the
routine: I wagged my tail. He froze. I have never seen a man so betrayed by kindness."*

## Run it

```sh
node main.ts
```

It writes the review to `/output/entry.txt`.
